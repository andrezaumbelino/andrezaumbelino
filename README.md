### Pipedrive BI Data Pipeline — Atlantic Bridge
**Python | BigQuery | SQL | Looker Studio**  
[View project](https://github.com/andrezaumbelino/ab-bi-data-pipeline)

End-to-end CRM data pipeline that extracts data from the Pipedrive API and loads it into Google BigQuery for analytics and dashboarding.

**Architecture:**  
Pipedrive API → Python (ETL) → BigQuery (Raw) → SQL (Dim/Fact) → Looker Studio

✔ Modular ETL design  
✔ Star schema data modeling  
✔ KPI-ready datasets  
✔ BI-optimized dashboards  

*All data is simulated and anonymized for portfolio purposes.*

### Hospital Performance Analytics — ClariHealth
**Power BI | DAX | Data Modeling**  
[View project](https://github.com/andrezaumbelino/healthcare-business-analytics)

End-to-end analysis of hospital performance, transforming healthcare data into insights for operational and strategic decision-making.

**Focus:**  
Operational efficiency, revenue drivers, and performance across hospitals.

✔ Star schema data model  
✔ KPI design: Revenue, Length of Stay, and Revenue per Day  
✔ Time intelligence with a calendar table  
✔ Executive dashboard in Power BI  

**Key finding from this analysis:**  
Operational efficiency, particularly length of stay, was the primary driver of performance rather than clinical mix.
